1. decimal используют для денежных расчётов, потому что он точнее представляет десятичные дроби. double хранит числа в двоичном виде, поэтому при вычислениях могут возникать ошибки округления
2. Если значение выходит за допустимый диапазон типа, происходит переполнение и выводится значение с начала нумерации списка
3. Тип переменной определяется компилятором во время компиляции по заданному значению и после этого не меняется
4. Console.ReadLine() возвращает строку string
5. int.Parse при вводе букв вместо числа приводит к исключению, например FormatException. int.TryParse не завершает программу с такой ошибкой, а возвращает false
6. false означает, что преобразовать введённую строку в int не удалось. В переменную через out при неудачном преобразовании попадёт в значение по умолчанию, для int — 0
