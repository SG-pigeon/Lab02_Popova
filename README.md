1.x += 5 — сокращённая запись x = x + 5. Для обычной переменной результат одинаковый.
2.x++ возвращает старое значение, а ++x — увеличенное.
3.Результат сравнения имеет тип bool: true или false.
4.Короткое замыкание — прекращение проверки логического выражения, когда результат уже известен. Например, age >= 18 && hasPassport: если возраст меньше 18, второе условие проверять необязательно.
5.10 - 2 * 3 + 4 / 2 = 10 - 6 + 2 = 6. Умножение и деление выполняются раньше сложения и вычитания.
6.Скобки делают порядок вычислений очевиднее и упрощают чтение кода.
